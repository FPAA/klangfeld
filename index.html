🎚️ Eigener Rhythmus
Klick auf ein Feld: laut → leise → aus · Mit gedrückter Maus über mehrere Felder ziehen · Klick auf den Namen = Klang anhören
Spielen: Klicken & ziehen = Melodie · Rechtsklick oder Shift = Akkord (bei „Immer Akkord“: Shift = Einzelton) · oben = hell & laut, unten = weich & dunkel · leuchtende Punkte = passende Töne zum Bass
Tasten: Leertaste = Loop · Z/C = Loop entfernen/löschen · B = Beat · L = Bass · G = Raster · D = Drone · A = Auto-Melodie · +/− = Tempo · R = Audio · H = Menü ein/aus · 1–9, 0 = Klang · ←/→ = Klang wechseln · ↑/↓ = Drone-Teppich wechseln · V = Optik · P = Alles an/aus · K = Immer Akkord · J / Shift+J = Akkordtyp · T = Tape-Stop · U = Build-up · X = Drop · I = Breakdown · F = Vollbild · W = Überrasch mich · Tab = Tastatur-Klavier (Y–M tief, A–L Mitte, Q–P hoch) · N = Gleiten · Maus/Taste halten = Ton klingt weiter (Orgel, Flöte, Streicher …) · Loop: wartet auf den Anfang der Akkordfolge und läuft bis zum Ende · ℹ️ INFO unten links = Anleitung & Lizenz
