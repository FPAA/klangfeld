Klangfeld ist ein Musik-Spielplatz für alle, ob mit oder ohne Musikkenntnisse. Du streichst mit Maus oder Finger über die Fläche, und es klingt immer harmonisch, weil nur Töne der gewählten Tonart vorkommen.

Auf Wunsch spielt eine ganze Band mit: Schlagzeug, Bass, Begleitung und eine Melodie, die sich von selbst weiterspinnt. Ein Klick auf eine von 84 Stimmungen bringt dich vom Bergsee in die Jazz-Bar, vom Lagerfeuer in den Techno-Club. Jedes Mal klingt es ein bisschen anders.

Nimm Loops auf, bau Spannung mit Build-up und Drop auf, lass den DJ-Modus durch die Stile wandern oder schlaf zu sanftem Regen ein. Alles wird live im Browser erzeugt: ohne Installation, ohne Internet, ohne Samples.
